STEJ Strong Deobfuscator

Pulihkan payload yang di-obfuscate dengan Strong Obfuscator (butuh kunci XOR yang sama)

DEOBF v1.0
Input (Obfuscated Code / Payload)
Output (Recovered)

Cara pakai:

  1. Paste kode hasil Strong Obfuscator ke kotak kiri
  2. Pastikan XOR Key sama persis dengan saat obfuscate
  3. Centang layer yang dipakai (XOR / ROT47 / HEX)
  4. Klik DEOBFUSKASI

Catatan: Control Flow Flattening & Junk code tidak di-reverse otomatis (hanya payload string yang dipulihkan).
